## 正文：每个词一块，六段固定

**单词** /音标/ *词性* 义项
- **拆字**：〔板面〕字母切分 → 谐音/词根
- **画面**：〔口述〕她描述的具体场景，用叙述体
- **台词**：〔口述〕她的原话，引号照抄。没有就写“（无）”
- **回锚**：从画面折回词义的那一句，写成 `X = Y → 词义`
- **例句**：〔板面〕原题/原句；被挡住的地方写 `[……]`，**不猜**
- **派生**：〔板面〕屏幕上列出的派生词

### 一条完整样例（grave）

```
**grave** /ɡreɪv/ *n.* 坟墓 *adj.* 严重的；严肃的
- **拆字**：〔板面〕gr（官人）+ ave → "官人爱（我）"
- **画面**：〔口述〕"官人爱我到坟墓——是不是到死都爱着你。"
- **台词**：〔口述〕"当名词讲是坟墓，当形容词讲是严重的——得的病都走向坟墓了，你说严不严重。"
- **回锚**：走到坟墓那一步的病 → 严重的
- **真题**：〔板面〕In Japan, the leakage of a state secret to R[……] grave crime.
- **派生**：〔板面〕gravity /ˈɡrævəti/ *n.* 重力，地球引力；严重性
```

**注意**：`台词` 和 `回锚` 分开写。她的口述里两者常挤在同一句，合并等于把我的理解伪装成她的原话。

### 附二：题外话

只收三类：跟她本人有关的、能单独引用的、半年后还想看的。
每条标出是在讲哪个词时说的，不要混进词义里。

### 附三：缺口

| 项 | 说明 |
|---|---|
| 只有词表没有板面的词 | 列出来，标“释义待核” |
| 例句英文 | OCR 丢空格，已按语义补分隔；被挡处 `[……]` |
| 音标 | 来自标题条，非 OCR |
| 口述轨 | 是否合并；摘要版还是全量 |
