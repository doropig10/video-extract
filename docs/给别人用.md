# 给别人用

## 先弄清你要给什么

| 对方想要 | 给什么 | 体积 |
|---|---|---|
| 只想拿笔记 | `outputs/` 里对应的 md 文件 | 几十 KB |
| 想让 AI 帮他做笔记 | `docs/发给AI_一份就够.md` 全文 | 21 KB |
| 想自己跑这套流程 | 代码 + 文档（不含 models / outputs） | 约 90 KB |
| 想接着改这个工具 | Git 仓库（含历史） | 约 90 KB |

**不要整目录打包。** 3.5GB 里有 3.4GB 是模型缓存、109MB 是取料素材，都不是代码。

## 打成最小包

```bash
# 在项目根目录
zip -r video-extract-src.zip . \
  -x "models/*" "outputs/*" "*.m4a" "*.wav" "*.mp4" "__pycache__/*" "*.log"
```

产物约 90KB，包含：`extract.py`、`scripts/`、`docs/`、`requirements.txt`、`install.sh`、`README.md`、`.gitignore`。

走 Git 更省事：

```bash
git init && git add . && git commit -m "init"
# .gitignore 已排除 models/ 与 outputs/
```

## 对方要准备什么

| 项 | 要求 |
|---|---|
| Python | 3.10 以上 |
| 系统 | Windows 需 Git Bash（01/02 是 bash 脚本）；macOS / Linux 直接可用 |
| 依赖 | `./install.sh`，想用 GPU 加 `--gpu` |
| 网络 | 首次要下模型：small 464MB / large-v3 3GB |
| 显卡（可选） | NVIDIA，8GB 显存可跑 large-v3 |

## 三步验收

```bash
./install.sh                              # 1 装依赖 + 自检
python extract.py "<任意B站链接>" -p 1 --probe-only   # 2 探一次，能看到格式清单就算通
python extract.py "<链接>" -p 1 --transcribe small   # 3 转一小段，能看到带时间戳的文本
```

第 2 步能出格式清单 = 网络与 yt-dlp 正常；第 3 步能出文本 = 转写链路正常。

## 大概率会遇到的三个问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `yt-dlp: command not found` | 脚本里写的是 `python -m yt_dlp`，但对方自己敲了裸命令 | 让他用 `python -m yt_dlp` |
| 转写报 `metadata_errors` | 直接把 m4a 喂给了 whisper | 项目已处理（先转 16k wav），除非他改了代码 |
| 模型下载 502 | HuggingFace 直连走代理 | `export HF_ENDPOINT=https://hf-mirror.com` |
| GPU 报 `cublas64_12.dll` | 没装 CUDA 库或没加 DLL 目录 | `./install.sh --gpu`；脚本已自动加目录 |
