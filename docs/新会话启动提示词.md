# 新会话启动提示词（复制即用）

> 用途：换一个聊天窗口后，让助手按同一套方法处理新视频，产出同格式笔记。
> 用法：整段复制下面「完整版」，替换最后三处占位符，发送。

---

## 极简版（懒人用，能跑但会漏细节）

流程和格式已经拆成两份，按需引用：

```
读视频按 video-extract/docs/A_怎么读视频.md，
记笔记按 video-extract/docs/B_怎么记笔记.md 里「模板 X」，
处理这个视频：<链接>
```

—— 不记单词、看别的类型时，只换模板编号就行（1 词汇课 / 2 概念课 / 3 教程 / 4 访谈 / 5 讲座）。

词汇类笔记的成品样式，参照 `video-extract/courses/P6_生态动物类/notes/刘晓艳六级词汇_P6_v7_拆字版.md`。

前提：同一个工作区、文件还在。换了电脑或换了目录，用下面的完整版。

## 完整版（推荐，自包含）

```
【任务】把这条视频整理成一份可复习的词汇/知识点笔记。

视频：<链接>   （如果是合集，注意 p=N 是第几个分 P）
内容类型：<口播为主 / 画面为主>   默认按口播为主处理
产出：Markdown，文件名 <课程名>_vN.md，放在 video-extract/courses/<课程名>/notes/ 下

【环境已经就绪，不要重新配】
- Python 3.13 在 ~/.workbuddy/binaries/python/versions/3.13.12
- yt-dlp 已装：python -m yt_dlp --version 能出版本号
- ffmpeg 已装（imageio-ffmpeg 自带二进制）：
  python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())"
- numpy、Pillow 已装
如果哪一步报"没有模块"，再 pip install，不要预先装一堆。

【流程】
1. 探测：python -m yt_dlp -I <P> -F "<链接>"
   确认：是否多分P、音频最高码率、视频可用画质、有无真字幕轨。
   注意：字幕列表只有 danmaku 就是没字幕（弹幕不是字幕）。
2. 取流：
   音频 python -m yt_dlp -I <P> -f "ba" -o "out/%(id)s.%(ext)s" "<链接>"
   画面 python -m yt_dlp -I <P> -f "30064" -o "out/src_%(id)s.%(ext)s" "<链接>"
   两条流分开下，不要合并（合并要 ffmpeg 且体积翻倍）。
3. 转写：用你自带的语音转写能力，喂本地 m4a，拿带时间戳的文本。
   【重要】转写对英文词会按中文谐音写错，实测 60 词错 10 个
   （stalk→stock、limb→lame、render→Rainer、famine/feminine→family、rage→"睿智"）。
   必须按上下文校正，并给出置信度（高/中/低）+ 判据。
4. 抽帧：ffmpeg 每 4 秒抽一帧缩到 480 宽做索引；
   只比画面左侧"文字区"做帧间差分，每 20 秒窗口取最静止的一帧，再去重；
   回到原片按全分辨率取帧，裁掉右侧人像（先试 1120 宽），3–4 张拼一页加时间戳。
   不要用场景检测——纯色背景换文字，直方图几乎不变，会漏。
5. 读板书：按行抄「词+音标 / 词性义项 / 记法句 / 例·真题 / 派生」。
   被讲师身体挡住的地方标 [ ]，猜不出来就留空。
6. 校对：屏幕上的记法（板面）和嘴上的记法（口述）经常不是同一套。
   【绝对不许合并】两套并排写，各自标来源，冲突单独列表。
7. 产出：五段式 + 来源标签。

【笔记格式（每条词固定五段，不许少段）】
（这一段只在记词汇课时用；其他内容换成 B_怎么记笔记.md 里的模板 2–5）

**word** /音标/ *词性* 中文义项
- **拆字**：字母切分 → 谐音/词根（每块含义）｜〔板面〕原句
- **画面**：〔口述〕她描述的场景，用她的话
- **台词**：她的原话金句，加引号
- **回锚**：从画面折回词义的那一句
- **例句**：〔板面〕或〔板面·真题〕原句
- **派生**：〔板面〕列出的派生词

拆字要写成看得见字母的形式，例如：
  e-co-lo-gy → "以靠了基"（依靠 + 养鸡）
  hum + able → 泥土 + 形容词后缀
不要写成"发音类似某某"这种纯描述。

【四条铁律，违反任一条重做】
1. 不编。没看到、没听到的一律不写。没场景就写"（无——她没讲场景）"。
2. 不合并两套记法。板面与口述冲突时并排保留，并注明建议背哪套（默认板面）。
3. 不隐藏不确定性。凡你改的、补的、猜的，必须标出来；校正表要带置信度。
4. 不越权。付费内容、番剧、充电专属不做；抓下来的东西仅限个人学习。

【交付前自检，逐条回答】
- 每条词五段都齐吗？缺的那段写"无"了还是偷偷删了？
- 有没有一句话是我编的？能追溯到某一帧或某一句原话吗？
- 板面与口述冲突的，我合并了吗？
- 我补的音标/义项，标"（板面未读到）"了吗？
- 转写校正表有置信度吗？中低置信度的，读者知道要回听吗？

交付时顺便告诉我：多少词、多少条有完整板面、哪些没读到、机器花了多久、你人工判断花了多久。
```

## 怎么验收它有没有偷懒

| 症状 | 说明 |
|---|---|
| 拆字写成"发音类似××" | 它把拆字降级成谐音提示了，退回重写 |
| 每条只有三四段 | 缺段没标"无"，是偷偷删的 |
| 一个"（无）"都没有 | 不可能所有词她都有场景，它在补脑 |
| 校正表没有置信度 | 它在假装自己全对 |
| "板面"和"口述"合在一句里 | 又混成第三套了 |
| 没提抽帧或没提音标 | 它八成只做了音频，没读画面 |

## 常用追加指令

- **嫌它编**：「把没有出处的话删掉，缺的地方写"（无）"。改完告诉我删了几条。」
- **嫌它短**：「内容长度不够是因为她只讲了这么多，不要扩写。要做的是把她讲的还原完整，不是加你的。」
- **只要她说的**：「只保留〔板面〕和〔口述〕，〔整理〕全部移到文末单独一节。」
- **要板书原文**：「抽帧不够，重新按 2 秒一帧抽，把被遮挡的词补上。」
- **要能背**：「按这个格式做可打印卡片：正面场景+台词，背面单词+音标+义项。」
- **要核对**：「把置信度为中的条目单独列出来，附上对应时间戳，我回原视频听。」

## 一句话总结

跟新助手交代时，三件事必须说清：**环境已就绪别重装**、**五段式不能少段**、**不许编也不许合并两套记法**。

其余细节它读完文档自然会做；这三条不说，它一定会在其中一条上翻车。
