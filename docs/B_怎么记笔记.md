## 一、四条通用规则（任何类型都适用）

### 1. 每条都要能回答"这是谁说的"

三种来源，永远分开标：

- 〔原文〕屏幕上写的 / 字幕里的 / 文档里的
- 〔口述〕人嘴里说的，转写稿里能查到
- 〔整理〕我补的（背景、词源、常识、我的判断）

**混在一起的后果**：读者无法判断哪句能引用、哪句要核实。更糟的是，混出来的文字往往比原文更顺——于是错误被文风掩盖。

### 2. 缺就是缺

没讲、没拍到、没听清，写"（无）""（未读到）""（此处存疑）"。

**不要用"合理推断"填空。** 一条标了"无"的笔记，比十条编得漂亮的笔记有用。

### 3. 冲突要保留，不要合并

同一件事出现两个版本（板书 vs 口述、字幕 vs 转写、两个嘉宾说法不一），**并排列出**，注明建议信哪个、为什么。

合并等于替当事人做决定，而且做错了没人能发现。

### 4. 改过的、猜的，必须可审计

凡我修正的原文（同音词、听错、拼写）、我补充的事实，都要能追溯到：

- 改了什么 → 原文是什么 → 依据是什么 → 置信度（高/中/低）

## 二、五种模板，选一个用

### 模板 1 · 语言 / 词汇课

一条词固定五段，缺段写"无"：

```
**word** /音标/ *词性* 义项
- 拆字：字母切分 → 谐音/词根（每块含义）
- 画面：讲者描述的场景（用他的原话）
- 台词：原话金句
- 回锚：从画面折回词义的那一句
- 例句：原文/真题原句
- 派生：原文列出的派生词
```

**关键**：拆字要写成看得见字母的形式（`e-co-lo-gy → "以靠了基"`），不要写成"发音类似某某"——那是提示，不是拆解。

### 模板 2 · 概念 / 原理讲解

```
## 概念名
- 一句话定义：〔原文〕
- 为什么重要：它解决了什么旧问题
- 机制：分 3–5 步，每步一句（不要一段长文）
- 例子：原文举的例子 + 我补的反例（标〔整理〕）
- 易混：和什么常被搞混，区别在哪
- 我的疑问：还没讲清的点，留待查证
```

**关键**：机制必须分步。一整段"因为 A 所以 B 导致 C"是最难复习的形态。

### 模板 3 · 操作 / 教程

```
## 目标：做完能得到什么
- 前置条件：环境、权限、依赖
- 步骤：
  1. 动作 → 预期结果（可验证）
  2. 动作 → 预期结果
- 坑：实测踩过的（症状 / 原因 / 解法）
- 回滚：搞砸了怎么退回去
```

**关键**：每一步都要有"预期结果"，否则读者不知道自己错在第几步。

### 模板 4 · 访谈 / 播客

```
## 主题
- 嘉宾/说话人 + 身份
- 核心观点（3–5 条，每条附原话引述）
- 支持观点的论据/故事
- 我不同意的 / 存疑的（标〔整理·我的判断〕）
- 待查：提到的书、人名、数据
```

**关键**：观点必须附原话。转述会不知不觉加入自己的理解。

### 模板 5 · 讲座 / 论文型

```
## 问题：作者想解决什么
## 方法：怎么做的（可复现的最小描述）
## 数据/证据：样本、来源、口径
## 结论：能推到什么程度
## 局限：作者自己承认的 + 我看出的
## 可复用点：对我有什么用
```

**关键**："结论"和"局限"必须分开写，否则容易把作者的推测当成事实。

## 三、通用骨架（不确定用哪个时）

```
# 标题（一句话说清这份笔记解决什么问题）
> 来源：链接 / 时长 / 日期

## 一句话结论
（读完这段，我该记住什么）

## 骨架（3–7 条）
（目录级别，让人能跳读）

## 细节（按骨架分节）
（每节：原文 / 口述 / 我的理解，三层分开）

## 存疑与待查
（我没搞懂的、互相矛盾的、需要回原视频核对的）

## 我的补充（单独一节）
（全部标〔整理〕，与上面物理隔离）
```

## 四、排版上的四条硬规矩

1. **一条一个信息点。** 一行里塞三件事，复习时谁也捞不出来。
2. **能表格就表格。** 对比、并列、参数，表格比段落快三倍。
3. **代码、命令、原句，一律用代码块或引号。** 它们一个字都不能被"顺手改写"。
4. **标题要能当目录用。** 扫一遍标题就该知道全文结构，不需要读正文。

---

## 五、自检清单（交付前逐条回答）

- 每节都能回答"这是原文、口述、还是我补的"？
- 有没有一句话找不到出处？删掉它。
- 标"无"的地方有几处？零处说明我在补脑。
- 冲突的地方合并了吗？合并了就拆回来。
- 读者能只凭这份文档判断"哪句能引用、哪句要核实"吗？

---

## 六、按内容类型避坑

| 内容 | 最容易犯的错 |
|---|---|
| 词汇课 | 把讲者的谐音记法扩写成故事（好听，但不是他的） |
| 概念课 | 把机制写成一段长文，失去结构 |
| 教程 | 步骤缺"预期结果"，读者卡住不知道错在哪 |
| 访谈 | 转述代替原话，混入自己的理解 |
| 讲座 | 把作者的推测写成结论 |
